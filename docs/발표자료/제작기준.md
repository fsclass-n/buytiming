- 발표자: 3조 조장 박미금. 팀원: 박미금, 김길동, 이오리, 홍기흥(원본 구성원 유지).
- 서비스: PickTiming(픽타이밍), 실시간 가격 비교와 구매 타이밍 추천.
- 발표: 본편 7장, 대본 170초 + 전환 여유 10초. 이후 웹 시연 420초.
- 코드·검증 기준: `279a4ce` (React UI 통합). 문서 갱신 기준일: 2026-11-05.
- 원본: `docs/프로젝트_발표자료.pptx`, 13장, 16:9. 기존 수집→비교→판정→설명→알림 흐름을 보존한다.
- 제출본: `docs/3조_최종발표_PPT.pptx`, `docs/3조_최종발표_PPT.pdf`.
  기존 PPT와 `docs/pdf/프로젝트_발표자료.pdf`도 동일한 내용으로 갱신한다.

## 디자인 철학 — Navy Signal

네이비는 장식보다 정보를 담는 공간으로 사용한다. 넓은 여백과 분명한 정렬로
심사위원의 시선이 제목, 근거, 결론 순서로 이동하게 한다. 가격을 고르고 시점을
판단하는 서비스의 성격은 작은 신호점과 절제된 연결선으로 표현한다.

Deep Navy `#0B1220`를 바탕으로 Dark Navy `#111C33` 카드가 층을 만든다.
Electric Blue `#2563EB`는 핵심 선택, Cyan `#22D3EE`는 데이터 흐름을 맡는다.
White `#F8FAFC`와 Light Gray `#CBD5E1`로 읽기 순서를 구분하며, 과도한 네온과
여러 색의 강조를 피한다. 미세한 선 두께와 여백까지 일관되게 조정한다.

Noto Sans KR의 굵은 제목과 보통 굵기 본문을 사용한다. 제목은 결론 한 문장,
본문은 짧은 기능명으로 제한한다. 긴 설명은 발표자 노트로 옮기고, 다이어그램과
실제 화면이 설명의 대부분을 맡게 한다. 작은 글자를 늘리는 대신 내용을 덜어낸다.

정보의 신뢰성을 시각적 완성도의 일부로 취급한다. 확인하지 못한 수치는 큰 숫자로
장식하지 않는다. 데모 화면과 운영 구조를 명확하게 구분하고, 실제 화면에는
출처를 표시한다. 도형과 텍스트는 PowerPoint에서 직접 편집할 수 있도록 제작한다.
최종 출력은 PDF로 다시 렌더링하여 줄바꿈, 도형 간격, 한글 글리프를 확인한다.

## 근거가 없어 제거하거나 확인 대기로 돌린 내용

원본의 설문 34명·79%·68%, F1 0.79, 수집 성공률 97.5%, 관심 상품 300종,
Gemini 500회 검증·환각 0건·JSON 99.8%·평균 2.2초·호출 62% 감소,
부하 오류율 0.3%, 기존 테스트 111건과 가상의 전후 수치는 검증 근거가 없다.
측정 보고서가 확보되기 전까지 구현 성과로 발표하지 않는다.

기존 진행일지의 교육 일정·단계 구분은 유지하되, 회의 개최·리허설 2회·발표회 피드백·
v1.0/v1.1 배포 등의 미확인 기록은 예정 또는 확인 필요로 정정한다.
원본의 조장·보고자 표기는 사용자 요청에 맞추고, 기존 구성원은 유지한다.
이전 서비스명과 폐기된 프런트엔드 경로도 바로잡는다.

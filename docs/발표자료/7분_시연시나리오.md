## 환경과 준비

- 주 시연: https://picktiming.netlify.app — 실제 UI, 브라우저 데모 데이터.
- 운영 확인용: https://picktiming.onrender.com — 독립된 FastAPI·TiDB 연동.
- Netlify의 상품·가격·AI 문장은 데모입니다. 실시간 Gemini 응답이나 실측 모델 성능으로 소개하지 않습니다.
- 실제 Gemini 응답을 별도로 보여 주려면 허용된 테스트 계정으로 사전 점검하고,
  응답의 `Gemini`/`규칙 기반 분석` 표시를 그대로 설명합니다. 운영 DB 회원가입·권한 변경은 시연에 넣지 않습니다.
- 브라우저 배율 100%, 데스크톱 해상도 1440px 이상. 발표 전에 홈·상품·관리자 화면을 한 번 열어 폰트와 차트 로딩을 마칩니다.
- 목표가·알림은 미리 초기화한 데모 브라우저 프로필에서 확인합니다. 화면 캡처는 `assets/`에 있습니다.
- 실제 7분 리허설 수행 여부와 소요 시간은 아직 확인하지 않았습니다. 아래 표에 맞춰 사전 연습합니다.

## 시연 중 피할 표현·동작

- 현재 최저가와 서비스에 기록된 역대 최저가를 혼동하지 않습니다.
- 적기 점수를 ‘정답 확률’ 또는 ‘추천 정확도’로 읽지 않습니다.
- 알림 저장만으로 새 목표가 도달 알림이 즉시 생성된다고 설명하지 않습니다.
- 데모의 쇼핑몰 A/B/C를 실제 제휴 쇼핑몰로 소개하지 않습니다.
- 권한 변경·회원 삭제·운영 데이터 초기화는 실행하지 않습니다.
- 소셜 로그인 키, 브라우저 저장 토큰, 환경 변수 창을 열지 않습니다.

# 설계 단계 산출물

이 문서는 현재 소스와 확인된 검증 결과를 기준으로 원본을 정정한 개정본입니다. 단계별 날짜와 시수는 원본 교육 계획을 보존한 것이며, 해당 날짜의 회의·실습·발표가 이미 수행되었다는 의미가 아닙니다. 개인별 개발 담당과 실제 수행일은 팀 확인이 필요합니다.

## 1. 데이터베이스 설계

| 테이블 | 역할 |
| --- | --- |
| users | 회원·권한·OAuth 식별 |
| products | 상품·모델·카테고리 |
| malls | 판매처 |
| product_listings | 상품의 판매처별 판매 페이지 |
| price_history | 판매가·배송비·실구매가·수집 시각 |
| public_prices | 선택적으로 수집한 공공 가격 |
| watchlist | 사용자별 관심 상품·목표가 |
| alerts | 사이트 알림·읽음 상태 |
| timing_predictions | 구매 적기 점수·판정 |
| ai_advice_logs | AI 호출·응답·검증 기록 |
| model_versions | 모델 버전·성능 메타데이터·학습 아티팩트 |

모델 정의는 backend/app/models.py가 기준입니다. 운영 TiDB를 로컬·Render·EC2가 공유하므로 운영 DB를 테스트 초기화 대상으로 사용하지 않습니다.

이전 스키마 이름 변경은 테이블 이동과 연결 주소 갱신을 함께 수행해야 합니다. 이 문서는 운영 마이그레이션의 실행 완료를 의미하지 않습니다.

## 3. 서비스 흐름

검색 → 상품 상세 → 판매처 비교·가격 차트 → 적기 신호등·AI 설명 → 관심 상품·목표가 → 사이트 알림.

회원가입: 필수 안내 동의 → 계정·관심 카테고리 → 계정 생성·로그인 → 첫 목표가 등록. 카테고리는 해당 브라우저에 저장되며 알림은 별도 API 저장 성공 후 완료 처리합니다.

## 5. 구매 적기 판정

30일 미만 이력은 판단 보류입니다. 활성 모델이 있으면 모델의 하락 확률을 사용하고, 없으면 규칙 기반 확률을 사용합니다.

점수 = (1 - 7일 내 5% 하락 확률) × 70 + (1 - 90일 가격 백분위) × 30.

70점 이상 구매 추천, 40~69점 관망, 40점 미만 대기 권장입니다. 점수는 구매 적합도 지표이며 예측 정확도나 구매 성공 확률이 아닙니다.

## 6. AI 설명과 권한 보호

Gemini에 분석 사실을 전달하고 응답 스키마·수치를 확인합니다. 수치 불일치·호출 실패·키 부재 시 정해진 설명으로 대체합니다. 이 장치가 모든 사실 오류를 제거한다는 뜻은 아닙니다.

서버 JWT·ADMIN 검증을 유지합니다. 테스트 관리자, 본인, 마지막 관리자 권한 변경 제한이 있습니다. 비밀번호 조건은 서버와 화면에서 확인합니다.

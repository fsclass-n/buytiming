## 1. ERD·테이블 정의서

### 1.1 관계 요약

- users 1 — N watchlist / alerts / ai_advice_logs
- products 1 — N product_listings / public_prices / timing_predictions / watchlist / alerts
- malls 1 — N product_listings 1 — N price_history
- model_versions 1 — N timing_predictions, rpa_job_logs는 독립 로그

### 1.2 테이블 정의

| 테이블 | 주요 컬럼 | 설명 |
| --- | --- | --- |
| users | id, email(UNIQUE), password_hash, name, role, created_at | 회원, 권한 USER / ADMIN |
| products | id, name, brand, model_no, category | 상품, 모델명은 매칭 기준 |
| malls | id, name, base_url, robots_checked_at, is_active | 판매처, robots.txt 확인일 |
| product_listings | product_id, mall_id, url, option_text, is_active | 상품-판매처 판매 페이지 |
| price_history | listing_id, price, shipping_fee, total_price, in_stock, collected_at | 가격 이력, 실구매가 = 판매가 + 배송비 |
| public_prices | product_id, good_id, price, store_type, survey_date | 참가격 공공데이터 |
| watchlist | user_id, product_id, target_price, notified_at | 관심 상품·목표가, 마지막 알림 시각 |
| alerts | user_id, product_id, type, message, is_read | TARGET_PRICE / TIMING_CHANGE |
| timing_predictions | product_id, model_version_id, current_price, min_90d, percentile_90d, prob_drop_7d, score, label, history_days | 판정 결과(BUY_NOW / WAIT_A_BIT / WAIT / HOLD) |
| ai_advice_logs | user_id, type, cache_key, cache_hit, source, tokens, latency_ms, validation, advice_json | AI 호출·검증 기록 |
| model_versions | version, algorithm, f1, precision, trained_rows, artifact, is_active | 모델 버전·성능·직렬화 파일 |
| rpa_job_logs | job_name, status, collected, failed, message, started_at, ended_at | 수집·배치 실행 이력 |

> 기준: backend/app/models.py. 테이블은 시작 시 create_all로 생성하며 별도 마이그레이션 도구는 사용하지 않습니다.

### 1.3 적기 판정 피처 및 점수 산식

| 피처 | 계산 방법 (backend/app/ml/features.py) |
| --- | --- |
| percentile_90d | 현재 일간 최저 실구매가가 최근 90일 분포에서 차지하는 위치(0 = 최저) |
| ratio_min_90d | 현재가 ÷ 90일 최저가 |
| gap_ma7 · gap_ma30 | 현재가 ÷ 7일·30일 이동평균 |
| slope_30d | 최근 30일 가격의 1차 회귀 기울기 |
| volatility_30d | 30일 표준편차 ÷ 평균 |
| days_since_drop | 직전 14일 최고가 대비 8% 이상 하락한 이후 경과일 |
| is_month_end | 월말 여부 |

- 라벨: 향후 7일 안에 현재가 대비 5% 이상 하락하면 1, 아니면 0
- 모델: RandomForestClassifier(n_estimators=150, max_depth=8, min_samples_leaf=3, class_weight=balanced), TimeSeriesSplit(5) 검증
- 교체: 학습 데이터 100행 이상, 검증 F1이 운영 모델 이상일 때만 활성화
- 점수: (1 − 하락 확률) × 70 + (1 − 90일 백분위) × 30
- 판정: 70점 이상 지금 구매 · 40~69점 조금 대기 · 40점 미만 기다리기 · 이력 30일 미만 판단 보류

### 3.4 Gemini 프롬프트 설계

| 구성 | 내용 |
| --- | --- |
| 시스템 지시 | 제공된 분석 수치만 사용하고 새 숫자를 만들지 않는다. 판정은 그대로 쓰고 summary 2문장, 근거 3개, 참고 고지 1문장으로 작성한다. |
| 입력 | 상품명, 최저 판매처 실구매가, 90일 최저·평균가, 백분위, 하락 확률, 점수·판정, 추세·할인 주기 |

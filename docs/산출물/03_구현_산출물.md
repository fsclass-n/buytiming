### 1.5 주요 코드

> 적기 점수 (backend/app/services/timing.py)
> prob = model.predict_proba(row)[0, 1] 또는 heuristic_prob(row)
> score = int(round((1 - prob) * 70 + (1 - pct) * 30))
> label = BUY_NOW(70 이상) / WAIT_A_BIT(40 이상) / WAIT, 이력 30일 미만은 HOLD

> 조언 생성 (backend/app/ai/gemini.py)
> generate_content(system_instruction, response_schema, temperature=0.3)
> unknown_numbers(응답, 입력 사실) → 있으면 위반 내용을 넣어 1회 재요청
> 재실패·오류·키 없음 → template_advice / template_chat

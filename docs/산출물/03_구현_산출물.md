# 구현 단계 산출물

이 문서는 현재 소스와 확인된 검증 결과를 기준으로 원본을 정정한 개정본입니다. 단계별 날짜와 시수는 원본 교육 계획을 보존한 것이며, 해당 날짜의 회의·실습·발표가 이미 수행되었다는 의미가 아닙니다. 개인별 개발 담당과 실제 수행일은 팀 확인이 필요합니다.

## 2. 프런트엔드 구현

React/Vite/Tailwind v4로 홈·검색·상품·차트·알림·가입 UI를 통합했습니다. 기존 Vanilla JS·Bootstrap 파일 구조는 현재 구현과 다릅니다.

7·30·90일 차트, 판매처·날짜 탐색, 카테고리·구매 추천 필터, 가격/점수 정렬, 목표가 모달이 연결되어 있습니다.

모달 Tab 순환·Escape·포커스 복구, 화면 이동 시 본문 포커스, 명시적 입력 레이블, 모바일 표 내부 스크롤을 적용했습니다.

고객 차트는 SVG입니다. Plotly는 관리자 통계 화면에서만 로드합니다. Unsplash 이미지는 참고 이미지로 표시합니다.

## 3. 백엔드·인증 구현

FastAPI 라우터와 SQLAlchemy 모델을 유지합니다. 이메일 가입·로그인, 서버의 비밀번호 조건, JWT·역할 검증, 회원 관리 API가 있습니다.

소셜 로그인은 Google·Naver·Kakao 제공자 설정과 콜백 주소가 필요합니다. 제공자 콘솔 설정과 실제 로그인 성공을 별도로 확인해야 합니다.

로컬 저장 토큰 방식은 현행 구현입니다. 보안 수준을 HttpOnly 쿠키 기반으로 구현했다고 표현하지 않습니다.

## 4. 분석·AI 구현

가격 이력에서 백분위·이동평균·추세·변동성·할인 간격 등의 피처를 생성합니다. RandomForest 학습과 시계열 검증 코드가 있습니다.

활성 모델 부재 시 규칙을 사용합니다. 모델 F1 실측 성과는 현재 보고서에 포함하지 않습니다.

Gemini 구조화 응답, 수치 대조, 재요청, 템플릿 대체, 조언 캐싱·사용량 집계가 구현되어 있습니다. 환각 0건이나 호출 감소율을 성과로 단정하지 않습니다.

## 5. RPA·외부 연동

등록 판매 페이지 수집·정제·전송, 네이버 검색 API 연결, Playwright 동적 페이지 수집, 선택적 S3 업로드 코드가 있습니다.

예시 쇼핑몰은 실제 판매처 접속 없이 모의 가격을 생성합니다. 참가격 수집에는 별도 주소·키·매핑이 필요합니다.

운영 자격 증명이나 DB 접속 문자열은 문서·발표 캡처에 포함하지 않습니다.

## 7. 남은 검증

실제 판매처 정책·수집 안정성, 모델 성능의 운영 데이터 검증, 외부 OAuth 로그인, EC2 연결·복구, 실사용자 평가를 추가해야 합니다.

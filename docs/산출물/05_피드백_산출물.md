## 3. 7분 시연

홈 → 검색·필터 → 상품 비교·차트 → 신호등·AI 설명 → 목표가 → 알림 → 가입 화면 → 관리자 조회 → 마무리.

Netlify의 실제 UI를 데모 데이터로 시연합니다. Gemini 실시간 응답·실제 제휴 쇼핑몰로 소개하지 않습니다. 운영 계정 권한 변경은 시연하지 않습니다.

세부 타임라인과 장애 대안은 발표자료/7분_시연시나리오.md를 사용합니다.

## 4. 예상 질문

| 질문 | 답변 기준 |

| 점수가 정확도를 뜻하나요? | 구매 적합도 지표이며 미래 가격 보장이 아닙니다. |
| AI가 틀릴 수 있나요? | 수치를 확인하고 재요청·대체하지만 모든 오류를 제거한다고 보장하지 않습니다. |

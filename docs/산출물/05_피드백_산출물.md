### 1.5 예상 질문과 답변

| 예상 질문 | 답변 요지 |
| --- | --- |
| 쇼핑몰 데이터 수집이 약관상 문제없나요? | robots.txt 확인 불가 시 수집하지 않고 3초 간격, 등록 판매처만 수집합니다. 실판매처는 이용 조건 확인 후 등록합니다. |
| AI가 틀린 숫자를 말하면? | 입력 수치와 대조해 재요청하고, 실패하면 정해진 설명으로 바꿉니다. 모든 오류를 없앤다고 보장하지는 않습니다. |
| 점수가 정확도인가요? | 구매 적합도 지표이며 미래 가격을 보장하지 않습니다. 화면에 참고 정보로 고지합니다. |
| 예측 모델은 어떻게 검증하나요? | 시계열 교차 검증 F1을 기록하고 이전 모델보다 같거나 좋을 때만 교체합니다. |
| 데모와 실제 서비스 차이는? | Netlify는 브라우저 데모, Render는 FastAPI와 TiDB를 사용하는 운영 환경입니다. |
| 알림은 어디로 오나요? | 현재는 사이트 내 가격 알림입니다. 모바일 푸시는 향후 과제입니다. |
| AI 비용은 어떻게 관리하나요? | 사용자별 일일 한도와 24시간 조언 캐시를 사용합니다. |
| 관리자 권한은 어떻게 보호하나요? | 서버에서 역할을 검사하고, 테스트 관리자·본인·마지막 관리자 권한 변경을 막습니다. |

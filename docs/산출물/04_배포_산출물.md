## 1. 검증 기준과 환경

검증 기준: 2026-11-05 / 코드 279a4ce / CI 41947934806. 기존 111건·500회 AI 검증 수치는 근거가 없어 현행 결과로 정정했습니다.

로컬 백엔드는 임시 SQLite, CI는 SQLite·MySQL 8을 사용했습니다. 브라우저는 로컬 데모와 가짜 HTTP 응답을 사용하며 운영 DB를 테스트로 초기화하지 않았습니다.

## 2. 테스트 결과

| 검사 | 확인 결과 | 범위 |
| --- | --- | --- |
| 백엔드 pytest | 51건 통과 | API·인증·권한·DB·SPA 등 |
| RPA pytest | 11건 통과 | 파서·정제·설정·스케줄 등 |
| 브라우저 Playwright | 9개 시나리오 통과 | 가입·검색·차트·목표가·권한·오류·반응형 |
| 화면 크기 | 375 / 768 / 1440px | 고객 경로별 페이지 가로 넘침 확인 |
| 접근성 자동 검사 | 검사한 홈·상품·가입·모달에서 오류 없음 | 정식 WCAG 인증이나 전체 조합 보장 아님 |
| CI·Docker | 통과 | React 빌드·SQLite/MySQL·RPA·이미지·헬스 |

MySQL CI는 같은 백엔드 테스트를 호환성 관점에서 재실행합니다. 별도의 신규 기능 케이스 수로 중복 합산하지 않습니다.

## 4. 배포 현황

| 환경 | 구성 | 확인 |
| --- | --- | --- |
| Netlify | 프런트엔드 데모 | 새 UI 반영 확인. API·DB 호출 없음 |
| Render | React+FastAPI 독립 풀스택 | 새 UI·/health·공개 추천 API 정상 응답 확인 |
| EC2 | nginx+API+RPA 구성 | 배포 설정 구현. 최근 Actions 실제 SSH 배포는 건너뜀 |
| TiDB | Render·EC2가 공유하도록 구성 | 운영 주소·키는 비공개. 스키마 변경 완료는 별도 확인 |
| 가격 수집 | Render용 GitHub 예약 작업 / EC2 컨테이너 | 실제 실행 로그·키·대상별 설정에 따라 동작 |

GitHub Actions 성공은 해당 외부 서비스의 실제 배포 완료와 동일하지 않습니다. Netlify·Render는 새 UI 자산까지 별도 확인했고, EC2 SSH 배포는 건너뛴 상태입니다.

## 5. 운영 체크리스트

배포 전: 비밀값 제외, 변경 경로 확인, 관련 테스트·빌드, 운영 DB 초기화 금지.

배포 후: /health, /js/config.js, React 자산, 공개 추천 API, 로그인·권한·수집 로그 확인.

문제 발생 시: 직전 정상 커밋으로 되돌리는 배포와 DB 복구는 별도로 판단합니다. 운영 데이터 삭제를 롤백 수단으로 사용하지 않습니다.

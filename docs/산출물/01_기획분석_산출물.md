이 문서는 현재 소스와 확인된 검증 결과를 기준으로 원본을 정정한 개정본입니다. 단계별 날짜와 시수는 원본 교육 계획을 보존한 것이며, 해당 날짜의 회의·실습·발표가 이미 수행되었다는 의미가 아닙니다. 개인별 개발 담당과 실제 수행일은 팀 확인이 필요합니다.

## 1. 프로젝트 기획서

픽타이밍은 여러 판매처의 가격을 비교하고 가격 이력을 바탕으로 구매 시점을 판단하도록 돕는 서비스입니다.

기존 자료의 핵심 문제 정의인 ‘어디서 살까’에서 ‘언제 살까’까지를 유지합니다. 설문 원자료가 없으므로 응답 인원·비율은 성과 근거에서 제외했습니다.

| 문제 | 해결 방향 | 기대 효과 |
| --- | --- | --- |
| 판매가·배송비가 제각각 | 배송비 포함 실구매가 비교 | 비교 기준 통일 |
| 현재 최저가만으로 시점 판단이 어려움 | 가격 이력·적기 점수·근거 설명 | 판단에 필요한 정보 제공 |
| 가격 확인을 반복해야 함 | 관심 상품·목표가·사이트 알림 | 반복 확인 부담 감소 |

## 5. 시스템 구성

| 영역 | 역할 | 현재 확인 |
| --- | --- | --- |
| Netlify | 프런트엔드 데모 | 새 UI 반영 확인. API·DB 호출 없음 |
| Render | React+FastAPI 독립 풀스택 | 새 UI·/health·공개 추천 API 정상 응답 확인 |
| EC2 | nginx+API+RPA 구성 | 배포 설정 구현. 최근 Actions 실제 SSH 배포는 건너뜀 |
| TiDB | Render·EC2가 공유하도록 구성 | 운영 주소·키는 비공개. 스키마 변경 완료는 별도 확인 |
| 가격 수집 | Render용 GitHub 예약 작업 / EC2 컨테이너 | 실제 실행 로그·키·대상별 설정에 따라 동작 |

사용자 → React 화면 → 같은 도메인의 FastAPI → TiDB. 수집기는 각 서버의 RPA API로 전송합니다. Netlify는 이 경로와 분리된 브라우저 데모입니다.

## 6. 개발 환경

| 영역 | 기술 |
| --- | --- |
| 프런트엔드 | React 19 · Vite 8 · Tailwind CSS v4 · FontAwesome |
| 화면·차트 | App.jsx 통합 고객 UI / SVG 가격 차트 / 관리자 Plotly 지연 로드 |
| 백엔드 | Python 3.11 · FastAPI · SQLAlchemy · JWT 인증 |
| 분석·설명 | pandas · scikit-learn RandomForest 또는 규칙 / Gemini 수치 검증·대체 응답 |
| DB | TiDB Cloud 공유 / SQLite 로컬 테스트 / MySQL 8 CI 호환성 검사 |
| 수집 | Requests·BeautifulSoup / 선택적 Playwright·네이버 쇼핑 API / 내장 스케줄러 |
| 배포 | Netlify 데모 / Render 독립 풀스택 / EC2 독립 풀스택 구성 |

Python 의존성은 루트 requirements.txt, 프런트엔드는 frontend/package-lock.json으로 관리합니다. 비밀값은 .env 또는 배포 서비스 설정에 둡니다.
